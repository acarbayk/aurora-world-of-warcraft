# Aurora Dreadnaught Add-on

Eski Tasha Armorer icin ucuncu zirh modeli (Dreadnaught / Juggernaut); DM onayli uyarlama.

Aurora > Additional Content alanina su adresi ekle:

https://raw.githubusercontent.com/acarbayk/aurora-world-of-warcraft/main/dreadnaught/dreadnaught.index

Tasha Armorer iceriginin kurulu olmasi gerekir. Aurora uygulamasinda test edilmemistir; gecici buyume, erisim ve silah degerlerini gerektiginde elle yonet. Daha once yerel XML yuklediysen cift kayit olmamasi icin onu kaldir.
